# Как получить .exe через GitHub (без программирования)

1. Зарегистрируйтесь на github.com (бесплатно).
2. Нажмите «+» вверху справа → New repository. Имя: duma. Выберите Private (приватный). Нажмите Create repository.
3. На странице нового репозитория нажмите ссылку «uploading an existing file».
4. Откройте папку проекта на компьютере, выделите ВСЁ внутри (Ctrl+A) и перетащите в окно браузера. Папка .github должна попасть тоже.
5. Подождите загрузки, внизу нажмите Commit changes.
6. Вверху откройте вкладку Actions. Сборка стартует сама, ждите 3–6 минут (жёлтый кружок → зелёная галочка).
7. Нажмите на завершённую сборку, внизу в разделе Artifacts скачайте DUMA-windows. Внутри ZIP будут установщик и portable-версия.

Если вместо галочки красный крест: откройте сборку и пришлите мне текст ошибки.
